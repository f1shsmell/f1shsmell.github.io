# 基于 Fuwari 模板搭建 GitHub 主页（博客向）

## 调研结论
- **模板**: Fuwari（saicaca/fuwari，5050★，MIT，Astro + Tailwind）——你已看过 demo 截图并选定。
- **部署**: 按官方方式用 `withastro/action` + `actions/deploy-pages` 的 GitHub Actions 工作流（Fuwari 不自带，需要新写）；仓库用 `f1shsmell.github.io`（用户主页仓库，无需 base path），地址 https://f1shsmell.github.io。
- **环境**: 本地目录为空；Node 24 / npm 11 / git / gh（已登录 f1shsmell）齐全；访问 GitHub 走 FlClash 代理 `127.0.0.1:7890`。
- **旧站**: 现有 f1shsmell.github.io 是你找的 astro-koharu 模板站（你说太花哨、稍后删除）。

## 实施步骤

1. **获取模板**：走代理 `git clone --depth 1 https://github.com/saicaca/fuwari` 到 `C:\Dev\GitHubPage`，删除 `.git` 后重新 `git init`（全新历史）。
2. **装依赖**：Fuwari 用 pnpm——通过 corepack 启用 pnpm 后 `pnpm install`。
3. **本地化改造**：
   - `src/config.ts`：站点标题（暂定 "f1shsmell's Blog"，可改）、作者 f1shsmell、语言 zh-CN、站点 URL；
   - `astro.config.mjs`：`site: 'https://f1shsmell.github.io'`；
   - 内容：删除示例文章，新增 2~3 篇中文占位文章（Hello World、博客使用说明），About 页改中文；头像/横幅先留占位并标注替换路径。
4. **新增部署工作流** `.github/workflows/deploy.yml`：push main 触发，`withastro/action`（自动识别 pnpm）构建 + `actions/deploy-pages` 发布，含 `pages: write / id-token: write` 权限。
5. **本地验证**：`pnpm build` 通过；`pnpm preview` 起本地服务，用浏览器截图确认中文渲染和布局正常。
6. **部署上线**：提交并推送。旧仓库处理——**默认直接以全新历史 force-push 覆盖现有 f1shsmell.github.io**（你已明确旧站废弃）；若你更想先自己删仓库我再重建，在批准时说明即可。随后确保 Pages 来源为 GitHub Actions（`gh api .../pages` 设置 `build_type=workflow`），等 Actions 构建完成。
7. **上线验证**：浏览器访问 https://f1shsmell.github.io 确认 200 且渲染正常（截图确认）。

## 风险提示
- git/pnpm 网络操作全部走 FlClash 代理；
- Fuwari 示例横幅图、头像需要你之后替换成自己的；
- Node 24 跑 Fuwari（CI 只测过 22/23）理论上兼容，构建报错时再调整 engines。
